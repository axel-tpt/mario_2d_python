# Mario 2D

## Installation

1. Clonez le dépôt :
   git clone git@github.com:axel-tpt/mario_2d_python.git
   cd mario_2d_python

2. Installez [uv](https://docs.astral.sh/uv/) puis les dépendances :
   ```bash
   uv sync
   ```

3. Lancez l'application (depuis la racine du projet) :
   ```bash
   uv run python -m mario_2d.main
   ```
